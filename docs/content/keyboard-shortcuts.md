# Keyboard shortcuts

Press **?** anywhere in the app to show this list. Every action can be done from the keyboard.

## Anywhere

| Keys | Action |
|---|---|
| <kbd>?</kbd> | Show these shortcuts |
| <kbd>Ctrl+Z</kbd> | Undo |
| <kbd>Ctrl+Y</kbd>, <kbd>Ctrl+Shift+Z</kbd> | Redo |
| <kbd>Ctrl+S</kbd> | Save the project as a .cdz file |
| <kbd>Ctrl+V</kbd> | Paste an image as a new graph |
| <kbd>Tab</kbd>, <kbd>Shift+Tab</kbd> | Move between controls |
| <kbd>Ctrl++</kbd>, <kbd>Ctrl+−</kbd> | Zoom the page or graph in or out (also Ctrl+wheel and pinch) |
| <kbd>Ctrl+0</kbd> | Fit the page or graph to the window |

## Tools

When not typing in a field.

| Keys | Action |
|---|---|
| <kbd>V</kbd> | Select tool |
| <kbd>P</kbd> | Add points tool |
| <kbd>H</kbd> | Pan tool |
| <kbd>C</kbd> | Calibrate tool |
| <kbd>T</kbd> | Guided trace tool |
| <kbd>M</kbd> | Colour mask tool |
| <kbd>X</kbd> | X-step tool |
| <kbd>L</kbd> | Loupe on or off |
| <kbd>S</kbd> | Magnetic snap on or off |

## Graph canvas

With the canvas focused.

| Keys | Action |
|---|---|
| <kbd>+</kbd>, <kbd>−</kbd> | Zoom in or out (also the mouse wheel) |
| <kbd>0</kbd> | Fit the image to the window |
| <kbd>1</kbd> | Actual size |
| <kbd>Arrow keys</kbd> | Pan (Shift: further), or nudge selected points |
| <kbd>Space+drag</kbd> | Pan with the mouse (also the middle button) |
| <kbd>Enter</kbd> | Show the keyboard crosshair, then click with the current tool |
| <kbd>Arrow keys</kbd> | Move the crosshair 1 px (Shift: 10 px) while it is shown |
| <kbd>Esc</kbd> | Hide the crosshair, or clear the selection |

## PDF page

With the page focused, while cropping.

| Keys | Action |
|---|---|
| <kbd>+</kbd>, <kbd>−</kbd> | Zoom in or out (also Ctrl+wheel) |
| <kbd>0</kbd> | Fit the page to the window |
| <kbd>Arrow keys</kbd> | Scroll the page |
| <kbd>Space+drag</kbd> | Pan with the mouse (also the middle button) |
| <kbd>Esc</kbd> | Clear the crop rectangle |

## Points

With the canvas focused.

| Keys | Action |
|---|---|
| <kbd>Arrow keys</kbd> | Nudge the selected points 1 px |
| <kbd>Shift+Arrow keys</kbd> | Nudge the selected points 0.1 px |
| <kbd>Delete</kbd>, <kbd>Backspace</kbd> | Delete the selected points |
| <kbd>Ctrl+A</kbd> | Select every point of the graph |
| <kbd>Shift+click</kbd>, <kbd>Ctrl+click</kbd> | Add to or remove from the selection |

## Data table

With a table cell focused.

| Keys | Action |
|---|---|
| <kbd>Arrow keys</kbd>, <kbd>Page Up</kbd>, <kbd>Page Down</kbd> | Move between cells |
| <kbd>Home</kbd>, <kbd>End</kbd> | First or last column (Ctrl: first or last cell) |
| <kbd>Enter</kbd>, <kbd>F2</kbd> | Edit the cell (or type a number) |
| <kbd>Enter</kbd>, <kbd>Tab</kbd> | Keep the edit and move down or right |
| <kbd>Esc</kbd> | Cancel the edit |
| <kbd>Space</kbd> | Select the row, or toggle Excluded |
| <kbd>Ctrl+C</kbd> | Copy the selected rows, or the whole table |

On a Mac, use Cmd in place of Ctrl.
